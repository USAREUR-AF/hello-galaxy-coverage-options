# Store: kastreni

Records written by the Kastreni Defence Integration Directorate, for a
notional nation. `systems/` describes Kastreni's own systems; `received/`
holds Kastreni's own record about a system another owner makes. `evidence/`
holds the notional documents, captures and library runs the records point to;
every `evidence=` and `sample=` path is relative to this directory.
