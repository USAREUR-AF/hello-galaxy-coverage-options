# Store: velmora

Records written by the Velmora Joint Integration Office, for a notional
nation. `systems/` describes Velmora's own systems. `received/` holds
Velmora's own record about a system another owner makes: it sits beside that
owner's record and does not replace it. `evidence/` holds the notional
documents, captures and library runs the records point to; every `evidence=`
and `sample=` path is relative to this directory.
